## Contenido del repositorio

- `index.html`: la página completa, en un solo archivo. No necesita instalación.
- `README.md`: esta guía.

## Cómo actualizar la página

1. Abrir el repositorio y pulsar **Add file**, luego **Upload files**.
2. Subir el `index.html` nuevo, con ese mismo nombre.
3. Pulsar **Commit changes**.
4. Esperar uno o dos minutos y recargar la página con Ctrl+F5.
